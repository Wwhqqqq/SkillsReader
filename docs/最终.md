自媒体场景梳理

# 需求背景
随着自媒体平台竞争加剧，内容创作者和运营团队需要持续、精准、高质量地产出符合平台传播规律的内容，因此希望引入一位自媒体内容创作专家，协助完成选题策划、内容撰写、脚本创作、标题优化和传播转化设计。

# 竞品调研
* 目前都集中在内容选题、排期、生成环节，没有涉及协助发布环节；输出内容为md、文档、图片、视频；输出平台主要针对微信公众号/小红书
* workbuddy：专家团、专家都有较好的完成度，可直接使用；但是各专家之间，专家与专家团之间的边界不是特别清晰，但是各有侧重
* coze：当前主要为skill概念
    * 自媒体分类四个技能包可整体调用，也支持单个skill调用
    * coze 部分skill进行了加密，不支持查看详情

生产-发布全链路

自媒体人的日常旅程，是围绕账号增长和商业化目标，持续完成“找题、找料、生产、发布、互动、复盘、复用”的循环

|**阶段**|**自媒体人的真实工作**|**关键环节**|**典型痛点**|**产品机会**|
|-|-|-|-|-|
|1. 明确经营目标|先想清楚最近要涨粉、接商单、卖课、卖货、引流私域，还是提升品牌影响力|阶段目标、平台目标、变现目标、内容方向|很多人每天都在发内容，但内容和业务目标脱节|帮用户把“业务目标”翻译成内容策略，比如涨粉内容、信任内容、转化内容的比例|
|2. 观察平台和同行|刷小红书、抖音、视频号、B站、公众号、知乎，看热点、爆款、同行表达|热点追踪、竞品拆解、评论区需求、搜索词、标签|信息太碎，只会收藏，不会分析；看了很多但不知道自己能不能用|移动端随手收藏，自动归类为热点、同行案例、用户问题、可改写选题|
|3. 捕捉灵感和素材|日常生活、客户咨询、评论区、私信、社群聊天、行业新闻都可能变成内容|截图、语音、链接、备忘录、案例、观点|灵感发生在手机上，真正写作时找不到；素材散在多个 App 里|移动端做“灵感入口”，桌面端做“素材整理台”|
|4. 选题策划|把热点、用户问题、个人经验、产品卖点转成可发布选题|选题池、系列栏目、内容日历、优先级|不知道写什么；选题零散；追热点但不符合账号定位|根据账号定位生成选题，并标注“涨粉/互动/信任/转化”目标|
|5. 内容排期|决定这周/今天发什么，什么平台发，什么时间发|周计划、日计划、平台节奏、定时提醒|靠临时灵感发内容，容易断更；多平台节奏混乱|定时任务推动：每周生成选题计划，每天提醒创作/发布|
|6. 内容制作|写小红书笔记、公众号文章、短视频脚本、口播稿、图文、朋友圈文案|标题、开头、正文、脚本、封面文案、结尾 CTA|写得慢；开头不抓人；结构散；AI 味重；不够像本人|基于账号人设、素材库、平台风格生成初稿，而不是泛泛写一篇|
|7. 拍摄/设计/剪辑|短视频创作者还要拍素材、剪辑、配字幕、选封面；图文创作者要配图、排版|拍摄脚本、分镜、字幕、封面、配图、剪辑节奏|创作不只是文字，图像和视频制作也耗时|生成拍摄脚本、分镜、封面标题、配图建议、字幕文案|
|8. 内容优化|发布前反复改标题、开头、结构、语气、标签、封面、互动引导|标题优化、平台适配、风险检查、可读性、评论引导|内容“能发”但不够好；不同平台语言差异大|提供发布前检查：标题吸引力、平台感、风险词、CTA、标签完整度|
|9. 多平台适配|同一主题可能要发小红书、抖音、公众号、视频号、朋友圈、知乎|长短互转、平台改写、格式适配|一稿多发效果差；逐个平台改很累|一键生成不同平台版本：小红书种草版、抖音口播版、公众号深度版、朋友圈转化版|
|10. 发布与分发|复制内容到平台，设置标题、封面、标签、合集、商品/链接/评论区引导|发布清单、发布时间、标签、首评、合集归档|发布前细节多；经常漏标签、首评、转化入口|移动端适合临场发布，桌面端适合准备发布包，定时任务提醒发布|
|11. 互动承接|发完后看评论、回复私信、引导关注、引导咨询、收集用户问题|评论回复、私信话术、线索识别、用户反馈|评论区有价值问题，但没有沉淀；潜在线索容易丢|自动整理评论/私信里的高频问题，生成回复建议和新选题|
|12. 数据查看|看阅读、播放、完播、点赞、收藏、评论、转粉、私信、成交|平台数据、内容表现、用户画像、转化表现|数据分散在各个平台；只知道爆了/没爆，不知道为什么|聚合或手动录入数据，形成内容表现看板|
|13. 复盘分析|判断这篇为什么好/不好，下次怎么改|选题复盘、标题复盘、发布时间、内容结构、评论反馈|很多人没有复盘习惯；复盘无法反哺下一次创作|发布后 24h/72h 定时提醒复盘，自动给出下次优化建议|
|14. 内容资产复用|把爆款内容拆成系列、改成脚本、做成课程片段、朋友圈、直播提纲|爆款库、素材库、结构库、案例库、FAQ|好内容用完就丢；没有沉淀成资产|建立“内容资产库”，支持旧内容翻新、拆条、系列化|
|15. 商业化经营|接广告、做带货、卖课、咨询、社群、私域转化|报价、合作脚本、产品种草、转化话术、客户案例|内容和变现割裂；广告太硬；产品卖点不会表达|帮用户把内容和商业目标连接起来：软广脚本、案例包装、转化路径设计|

* WiseFlow 的 xhs-content-ops / xhs-interact 虽为社区发布，但是 WiseFlow 官方 crew 包组件，小红书侧最接近「官方工作流」
